# Solutions — 01 Computer Foundations

> **⚠ Attempt the exercises before opening anything here.**
>
> A solution read first produces recognition — which feels like knowledge and is not. These files
> exist to *check* work you already did and to show reasoning you can compare against, not to
> replace the attempt. If you have not attempted yet, close this folder and go back to
> [../README.md](../README.md).
>
> If you did attempt and got stuck: read the reasoning, then **rebuild the answer from a blank page
> one week later without looking** — that rebuild is what you actually keep.

## What is in here

`set-1-solutions.md` … `set-7-solutions.md` correspond one-to-one with the exercise sets in
[../README.md](../README.md).

Each solution file contains, per exercise:

- the **final answer**, clearly labeled;
- the **reasoning steps**, not just the conclusion (for the independent tasks: the trade-offs and
  the alternatives considered);
- the **criteria check** — each completion criterion ticked, so you can grade yourself honestly;
- where an exercise is open-ended (triages, designs), **one defensible reference answer plus the
  weaknesses a reviewer would raise**, since open problems rarely have a single right answer.

Nothing here is a substitute for the knowledge checks in the lessons: if you can reproduce these
reasoning steps cold a week later, you are at the level the subject's completion criteria describe.
